# Swipets 🐾

> **Building a Tinder for Pet Finding.** Facilitating connecting pets to their forever homes! A modern, Tinder-style Progressive Web App (PWA) for pet adoption and matchmaking.

---

## 🌟 Key Features

- **Tinder-style Swipe Matcher:** Smooth gesture-based swiping to like or pass on adoptable pets (`framer-motion`).
- **Comprehensive Filtering:** Filter pets by species (Dogs, Cats, Small Animals) and personality traits (kid-friendly, energetic, chill, etc.).
- **Favorites & Adoption Forms:** Saved matches with integrated adoption inquiry forms.
- **Community Lost & Found Hub:** Area for community members to report and track lost or found pets.
- **Social Feed:** Unified social media feed aggregating pet updates and stories.
- **"Flying Cat" Mini-Game:** Built-in HTML5 Canvas game with custom SVG sprites and physics.
- **PWA Ready:** Installable on iOS, Android, and Desktop with offline support.
- **Science-Backed Aesthetic:** High-contrast dark theme optimized for visual attention and reduced eye fatigue.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MagnusDrake/swipets.git
   cd swipets
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack

- **Frontend:** React 19, React Router v7
- **Build Tool:** Vite + `vite-plugin-pwa`
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Styling:** Vanilla CSS & Glassmorphism Design Tokens
